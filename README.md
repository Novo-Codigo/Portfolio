# Portfolio | Samuel Melo

Portfólio estático autônomo (HTML, CSS e JavaScript puro).

## Estrutura

- `index.html`: Ponto de entrada contendo toda a estrutura, estilos, ícones vetoriais embutidos e interações com Canvas / Web Audio API.

## Execução local

Qualquer servidor de arquivos estáticos pode ser utilizado:

```bash
python3 -m http.server 8000
```

Acesse em `http://localhost:8000`.
